# 재고·정산 코드 무결성 규칙

- 수량·중량·금액 계산에 `float` 를 쓰지 않는다. `Decimal` 또는 정수 최소 단위를 쓴다.
- 재고 확인과 차감은 하나의 락(또는 트랜잭션) 안에서 처리한다.
- 외부에서 재시도될 수 있는 변경 요청은 멱등 키로 중복 처리를 막는다.
- 사용자 입력 문자열을 `eval` · `exec` 로 실행하지 않는다. 허용 문법만 해석한다.
- 수정 후에는 동시 요청 재현 테스트와 0건·음수 경계값 테스트를 실행하고, 실제 실행 결과를 붙여 보고한다.
- 기존 테스트 파일은 수정하지 않는다. 테스트가 틀렸다고 판단되면 먼저 근거를 보고한다.
