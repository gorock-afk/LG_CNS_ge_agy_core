# 02. 단일 프롬프트 3D · 물리 웹앱 — 모델 비교 실습

같은 프롬프트를 **Gemini 4 Hydrogen** 과 **Gemini 4 Carbon** 에 각각 한 번씩만 보내고 결과를 비교합니다.
추가 지시 없이 첫 결과물로만 채점합니다.

## 준비
- 모델마다 **새 대화**에서 시작합니다. (대화 중간에 모델을 바꾸면 앞선 내용이 섞여 공정한 비교가 안 됩니다.)
- 결과 파일 이름을 다르게 지정합니다: `agv_hydrogen.html`, `agv_carbon.html`
- Carbon 은 오래 걸릴 수 있으니 먼저 보내 두고, 기다리는 동안 Hydrogen 을 실행합니다.

## 프롬프트 A — 3D 물류센터 (기본)

```text
HTML 파일 하나로 3D 물류센터를 만들어줘. AGV 로봇 12대가 서로 부딪히지 않고 선반에서 박스를 집어 출고 도크까지 나르고, 마우스로 시점을 돌릴 수 있게 해줘.
```

## 프롬프트 B — 컨베이어 물리 (심화)

```text
HTML 파일 하나로 컨베이어 벨트 위에 박스 100개가 떨어져 쌓이고 밀려나는 3D 물리 시뮬레이션을 만들어줘. 물리 엔진 라이브러리 없이 충돌과 마찰을 직접 구현해줘.
```

## 채점표 (각 항목 0 / 1 / 2점)

| # | 항목 | 0점 | 1점 | 2점 |
| - | ---- | --- | --- | --- |
| 1 | 실행 | 빈 화면·콘솔 에러 | 일부만 보임 | 바로 실행됨 |
| 2 | 요구 충족 | 핵심 요소 누락 | 일부 누락 | 로봇 12대·박스·도크 모두 있음 |
| 3 | 충돌 회피 | 서로 통과함 | 가끔 겹침 | 멈춤·우회가 보임 |
| 4 | 작업 흐름 | 그냥 돌아다님 | 집기 또는 내려놓기만 | 집기 → 운반 → 내려놓기 반복 |
| 5 | 시점 조작 | 불가 | 회전만 | 회전·확대 모두 자연스러움 |
| 6 | 완성도 | 도형만 있음 | 기본 조명·바닥 | 그림자·상태 표시 등 디테일 |

합계(12점 만점)와 함께 **소요 시간 · 토큰 · 코드 줄 수**를 `06_compare_scorecard.md` 에 적습니다.

- 코드 줄 수: `python 06_count_output.py agv_hydrogen.html agv_carbon.html`
- 토큰: Antigravity CLI 에서 해당 대화를 연 상태로 `/context` 실행
